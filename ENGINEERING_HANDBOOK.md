# Engineering Handbook - Phase 10

Long-term engineering handbook and onboarding checklists.

## 1. Coding Standards
* **Strict Typing**: Strict TypeScript typings must be maintained without exception.
* **Component Composition**: Visual changes must compose existing elements from `@ai-video-editor/ui` to prevent visual shift discrepancies.

## 2. Review Checklist
* Ensure zero business-logic changes in presentation packages.
* Ensure all tests pass cleanly before merging branches.
