# Design System 4.0 Reference

Design System 4.0 establishes a single, desktop-first, dark-first source of truth for the entire RR Smart Editor platform.

## 1. Color Palette (Dark Theme Standard)
* **Background Main (`bgMain`)**: `#050b14` (Ultra-dark base)
* **Background Paper (`bgPaper`)**: `#0d1527` (Panel depth surface)
* **Background Secondary (`bgSecondary`)**: `#12203d` (Interactive cards/hover states)
* **Borders (`border`)**: `#1b2f54` (Pixel-perfect divider lines)
* **Border Hover (`borderHover`)**: `#33528a`
* **Accent Primary**: `#00f0ff` (Cyberpunk Cyan)
* **Accent Secondary**: `#ec4899` (Magenta Highlight)

## 2. Spacing Scale
* **`xs`**: `4px`
* **`sm`**: `8px`
* **`md`**: `16px`
* **`lg`**: `24px`
* **`xl`**: `32px`

## 3. Corner Radii
* **`sm`**: `4px` (Buttons, inputs)
* **`md`**: `8px` (Floating dialogs, custom panels)
* **`lg`**: `12px` (Outer dashboard cards)

## 4. Typography Scale
* **Family**: `"JetBrains Mono", "Inter", "Segoe UI", system-ui, sans-serif`
* **Sizes**:
  * `caption`: `0.7rem`
  * `body2`: `0.8rem`
  * `body1`: `0.9rem`
  * `subtitle`: `1rem`
  * `title`: `1.25rem`
