# Admin Guide

Enterprise and system administration reference for the RR Smart Editor Studio Platform (v3.0).

## 1. Compliance and Governance

Use the Administrator Console to:
- Enforce **Retention Policies**: Configure automatic archival periods for asset files.
- Apply **Legal Holds**: Lock specific campaigns from being deleted or pruned during audits.
- Export **Audit Logs**: Download comprehensive transactional logs for enterprise reports.

## 2. Managing the Marketplace

Marketplace administrators audit and moderate extension uploads. You can:
- Feature high-performance plugins or templates.
- Publish security advisories.
- Deprecate outdated extensions.
