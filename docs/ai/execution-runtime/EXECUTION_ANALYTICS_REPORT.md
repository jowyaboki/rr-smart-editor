# Execution Analytics Report

## Metrics Measured
- **Execution Duration**: Real-time tracking of overall and per-node duration in milliseconds.
- **Scheduler Dispatch Latency**: Sub-millisecond task enqueue and dispatch timing.
- **AI Productivity Score**: Percentage of completed vs failed node executions.
- **Checkpoint Efficiency**: Checkpoint write latency and frequency efficiency score.
- **Human Intervention Frequency**: Number of requested approval gates during execution.
