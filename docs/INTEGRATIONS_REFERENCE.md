# Integrations Reference

The integrations hub provides native, plug-and-play connectors for enterprise storage, workspace collaboration, and development tools.

## 1. Enterprise Storage Connectors
- **AWS S3**: Secure asset uploading using presigned URLs.
- **Azure Blob Storage**: Automated multi-tier archiving to cold container segments.
- **Google Cloud Storage (GCS)**: Integrated CDN proxying for global asset caching.

## 2. Workspace & Task Management Connectors
- **Notion**: Automated sync of scene transcripts and review timelines.
- **Jira & Linear**: Spawns development or editing tickets directly from frame comment flags.
- **Google Workspace & Microsoft 365**: Single Sign-On (SSO) and direct asset imports.

## 3. Creative Ecosystem Connectors
- **Adobe Creative Cloud**: Adobe Premiere and After Effects asset syncing.
- **Blackmagic Cloud**: High-performance multi-user project synchronization hooks.
