# Creative Variants & Aspect Ratio Management

## Aspect Ratio Adaptations
The `CreativeVariantsPanel` supports instant multi-platform variants from a single core project:
- **YouTube / Broadcast**: 16:9 Landscape
- **TikTok / Instagram Reels**: 9:16 Portrait
- **Instagram Feed**: 1:1 Square

## Asset Reuse
Variants reference identical underlying media URIs and storyboard specs, eliminating redundant asset copies and storage bloat.
