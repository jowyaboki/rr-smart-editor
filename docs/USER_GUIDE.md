# User Guide

This guide helps video editors, producers, and directors utilize the unified RR Smart Editor Studio Platform (v3.0).

## 1. Navigating the Studio Workspace

The Studio Workspace is divided into:
- **Productions List**: Overview of active campaigns, tasks, and upcoming milestones.
- **Media Ingest**: Drag and drop footage. Automatic duplicates are flagged immediately.
- **Timeline Canvas**: The classic multi-track editing workspace.

## 2. Review and Collaborating

Directors and clients can review draft video cuts using a web link:
- **Frame Comments**: Jump to specific frames and add feedback.
- **Draw Annotations**: Draw red-line shapes directly on the video canvas.
- **Approve**: Submit a single-click approval request to transition the production stage.
