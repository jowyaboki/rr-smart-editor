# Long-Term Support (LTS) Policy

This document defines the release lifecycle and support boundaries for the RR Smart Editor Studio Platform (v3.0).

## 1. LTS Release Cycles

Every major release (v3.0, v4.0) receives active support and security maintenance according to the following windows:

- **Active Support**: 18 Months. Active development of minor feature additions and performance enhancements.
- **Maintenance Support**: 12 Months. Critical bug fixes and security patching.
- **End of Life (EOL)**: 30 Months after first release. Support is discontinued.

## 2. Backward Compatibility Guarantee

All LTS releases guarantee full backward compatibility for:
- Database schemas from v1.x and v2.x.
- Core Public SDK method signatures.
- Verified and certified Marketplace plugin APIs.
