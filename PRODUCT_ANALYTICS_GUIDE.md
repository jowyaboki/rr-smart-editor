# Product Analytics Guide - Phase 10 (Product Evolution)

Guide detailing core usage analytics and metric tracking.

## 1. Core KPIs
* **Daily Active Users (DAU)**: Active creators launching the workspace.
* **Retention (Weekly/Monthly)**: Customer retention metrics.
* **AI Feature Adoption**: Accepted versus rejected copilot edits.
* **Distributed Renders**: Render pipeline volumes and cost aggregates.
