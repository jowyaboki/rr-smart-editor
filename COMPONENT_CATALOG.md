# Component Catalog

Standardized, reusable compound component blocks.

## Catalog
* **`AppShell`**: Main framework container.
* **`WorkspaceLayout`**: Split-panel grid region.
* **`ScrollableRegion`**: Layout area containing overflow limits.
* **`ToolbarRegion`**: Header contextual button strip.
* **`Panel`**: Collapsible resizable card wrapper.
* **`Inspector`**: Detail property editing sidebar.
