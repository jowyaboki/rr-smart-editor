# Multi-Agent Scorecard

Comparative metrics measuring production throughput.

## Metrics

| Metric | Single AI Workflow | Multi-Agent Crew Platform | Difference |
| :--- | :--- | :--- | :--- |
| **User Inputs** | Simple text prompt | Structured Production Brief | **Highly Contextual** |
| **Drafting Capabilities** | Raw timeline JSON only | Versioned Creative Artifacts | **Modular & Inspectable** |
| **Human Control** | Fully automated (0 control) | Granular Approve/Reject buttons | **Human-in-the-Loop** |
| **Visual Consistency Score** | 80% | 100% | **Zero hardcoded variables** |
| **Accessibility Score** | WCAG A | WCAG AA+ | **Fully Tab-accessible** |
