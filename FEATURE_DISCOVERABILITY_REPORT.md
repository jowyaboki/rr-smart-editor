# Feature Discoverability Report

Features reveal themselves organically throughout standard editing cycles.

## Discoverability Channels
* **Fuzzy Command Search**: Accessing shortcuts via `Ctrl+K` instantly lists macros, layout resets, and recent settings.
* **Contextual Suggestions**: Recommendations dynamically adapt to the active select track item.
* **Empty States & Onboarding**: Guides users to import media files without cluttering secondary navigation lists.
