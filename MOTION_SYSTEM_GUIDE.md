# Motion & Transition System Guide

The Studio UI v5 features premium, physics-informed micro-interactions.

## Animation Specs
* **Standard Transition Curve**: `cubic-bezier(0.4, 0, 0.2, 1)` (smooth deceleration).
* **Hover Scale**: Hovering over media tiles or navigation items applies a 1.02x scale shift.
* **Selection Glow**: Outline glow animations ease over `0.15s` matching the accent primary colors.
