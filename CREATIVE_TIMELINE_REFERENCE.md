# Creative Timeline Reference

A production management timeline independent from the editing timeline.

## Stages
1. **Planning**: Objective brief definition.
2. **Writing**: Voiceover script drafting.
3. **Storyboard**: B-Roll placeholder mapping.
4. **Editing**: Multi-track clip assembly.
5. **Review**: Subtitle translation and frame feedback.
6. **Rendering**: Cluster sharding.
7. **Publishing**: Final asset packaging.
