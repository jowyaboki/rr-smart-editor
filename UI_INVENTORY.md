# UI Inventory Audit

Comprehensive visual catalog across all application route configurations and active workspace layouts.

## Pages & Workspaces
* **Dashboard (`apps/web/src/pages/Dashboard.tsx`)**: High contrast project launcher with live metrics, search filter, and system diagnostics tables.
* **Editor Workspace (`apps/web/src/pages/Editor.tsx`)**: Flagship desktop workspace supporting collapsible columns, split-pane resizers, multi-track timelines, and real-time inspector sliders.
* **Preview Viewport (`apps/web/src/pages/Preview.tsx`)**: Framing view with aspect envelopes and Remotion player integrations.
* **Templates & Assets (`apps/web/src/pages/Templates.tsx`)**: Form structures, visualizer configurations, and card lists.

## Primitives and Atoms
* **`Panel`**: Collapsible resizable card panel.
* **`Inspector`**: Attribute editing sidebar layout.
* **`PropertyGrid`**: Aligned key-value metric rows.
* **`CommandPalette`**: Global fuzzy command finder.
