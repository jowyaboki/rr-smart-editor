# Universal Command Palette Guide

The Universal Command Palette is the flagship navigation and command dispatcher for the RR Smart Editor workspace.

## Usage
* **Trigger Shortcut**: Press `Ctrl+K` or `Cmd+K` anywhere.
* **Navigation**: Use Up/Down keys to navigate list options and Enter to dispatch.
* **Fuzzy Search**: Filter instantly across:
  * Route Navigation (`Go to Projects`, `Go to Media`, `Go to Render`)
  * Layout Presets (`Focus Mode`, `Editing Mode`, `Color Mode`, etc.)
  * Workflow Automation & AI edit triggers.
